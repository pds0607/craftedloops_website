# Crafted Loops website

Product catalogue and inquiry website for [Crafted Loops](https://craftedloops.art), built with Next.js, React, TypeScript, and Vite/Vinext.

## Development

```bash
npm ci
npm run dev
```

## Checks

```bash
npm run lint
npm test
```

The production build is written to `dist/`. The PHP inquiry handler is copied from `public/send-inquiry.php` into the static output for hosting.
